# media/ フォルダについて

商品ごとに使い回す画像・動画を置く場所です。

## 使い方

1. `products.json` の商品に `"media_dir": "フォルダ名"` を追加する
2. `media/フォルダ名/` を作り、その商品の画像(.jpg/.jpeg/.png)・動画(.mp4/.mov)を好きなだけ入れる
3. 投稿を自動生成するとき、その商品が選ばれたら **このフォルダの中身を全部** 使って投稿する
   - 1件だけなら単一画像/動画の投稿
   - 2件以上ならカルーセル投稿(画像・動画の混在も可、Threads APIの上限20件まで)
4. `media_dir` を指定しない商品、またはフォルダが空の商品は、従来通りテキストのみの投稿になる

## 公開URLについて(重要)

Threads APIはローカルファイルを直接アップロードできず、画像・動画は「インターネット上の
公開URL」を指定する必要があります。そのため、このフォルダを外部に公開しておく必要が
あります(README本編の「メディア(画像・動画)の公開設定」を参照)。

`.env` に `MEDIA_BASE_URL`(例: `https://あなたのユーザー名.github.io/公開用リポジトリ名`)
を設定すると、`media/フォルダ名/ファイル名` が
`MEDIA_BASE_URL/フォルダ名/ファイル名` という公開URLとして自動的に組み立てられます
(このリポジトリの中身をそのままGitHub Pagesなどで公開してください。公開リポジトリの中に
さらに「media/」という入れ子フォルダを作らないでください)。

`MEDIA_BASE_URL` が未設定のままだと、画像・動画付きの商品でもテキストのみの投稿にフォール
バックします(エラーにはなりません)。
